# cr-sandbox-test

Small Node.js application used as a QA fixture for the CodeRabbit Verify coding
environment. It has no third-party dependencies and listens on `PORT` (default
`3000`).

## Pages

- `/` — home page
- `/submit` — demo form
- `/about` — about page
- `/health` — readiness check

## Running

```bash
npm start
```
